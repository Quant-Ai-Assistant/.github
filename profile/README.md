## What Quant is

Quant is an open-source alternative to OpenAI Dots, Meta Muse, Grok Bot, Instinct, Manus Cue, Claude Cowork and ChatGPT agent: a personal AI assistant that belongs to the person who runs it. At its center is **Quant-Core**, built on [Rakazo](https://github.com/elie222/rakazo): a server you host yourself, where AI agents keep working 24 hours a day, remember what they were doing and come back with results.

Quant is an ecosystem, not a single app. The same assistant is meant to be reachable from every device you own, to work with the services you already use, and to live inside hardware you can build yourself: each device repository carries the schematics and instructions to make it.

## Planned

Nothing in this section exists yet.

- **Apps for every device:** the same assistant on Android, iOS, macOS, Linux and Windows.
- **Integrations:** connections to the services people already use, so the assistant can act there on their behalf.
- **More devices:** new hardware for the ecosystem, each one open and buildable from its repository.

## Principles

- **The person who runs it owns it.** Data, memory and credentials stay on infrastructure they control.
- **One assistant everywhere.** A phone, a laptop and a speaker in the kitchen talk to the same agents with the same memory.
- **Hardware is documentation too.** A device is not finished until someone else can build it from the repository.
- **Honest about limits.** Each project says what it does not do.
- **Open all the way down.** No closed components that the rest depends on.
